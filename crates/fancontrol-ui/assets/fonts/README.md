# Noto Sans CJK (vendored)

`NotoSansCJK-Regular.ttc` provides Chinese/Japanese glyph coverage for the UI's
i18n support (egui's bundled default fonts have no CJK glyphs).

- Source: https://github.com/notofonts/noto-cjk (`Sans/OTC/NotoSansCJK-Regular.ttc`)
- License: SIL Open Font License 1.1 (`OFL.txt` in this directory, copied from `Sans/LICENSE` in that repo)
- Merged OTC covering Simplified Chinese, Traditional Chinese, Japanese, and Korean in a single file, single weight (Regular)
